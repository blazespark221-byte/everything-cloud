# Specs Explains: Weird But True

A 7-minute (420 s) animated short made with [HyperFrames](https://github.com/heygen-com/hyperframes)
(HTML compositions rendered to video). The host is **Specs**, a stick figure in round glasses and a
coral bow tie, who pulls questions out of his Question Jar and answers six facts that sound made up:

| Time | Scene | Question |
| --- | --- | --- |
| 0:00 | `intro` | Specs, his glasses and the Question Jar |
| 0:28 | `sky` | Why is the sky blue? (sunlight's colours, Rayleigh scattering, sunsets) |
| 1:50 | `octopus` | Do octopuses have three hearts? (and blue blood, and thinking arms) |
| 2:54 | `banana` | Is a banana a berry? (and why strawberries aren't) |
| 3:44 | `honey` | Does honey ever go bad? (three tricks, and crystals) |
| 4:45 | `taller` | Are you taller in the morning? (spinal discs, astronauts) |
| 5:36 | `venus` | Is a day on Venus longer than its year? |
| 6:30 | `outro` | Recap and the last note |

The rendered film is `renders/specs-explains.mp4` (1920 x 1080, 30 fps, H.264 + AAC).

## Preview and render

```bash
npm run dev                 # Studio preview of index.html
npm run check               # lint + runtime + layout + motion checks
npm run render              # writes renders/<name>.mp4
```

On machines where HyperFrames cannot download Chrome, point it at an existing headless shell with
`PRODUCER_HEADLESS_SHELL_PATH=/path/to/headless_shell`.

## How it is put together

- `index.html` is generated by `tools/build.mjs`: one host per scene, the eight voice tracks, the
  music bed and every sound effect at its film time. Do not hand-edit it; edit `script/sfx.json` or the
  scenes and re-run the build.
- `compositions/<scene>.html` holds each scene: SVG drawings plus one paused GSAP timeline. Every
  reveal is keyed to a spoken line through `Kit.cues(scene)` (line starts/ends from
  `assets/data/timing.js`), so changing the script or its pauses re-times the pictures automatically.
- `assets/specs.js` is the rig that draws Specs from time alone: pose and face keyframes, head-leads /
  arms-follow offsets, automatic blinks, a 12 fps line boil, IK legs that keep his feet planted, walking
  and hopping, and a mouth driven by `assets/data/lipsync.js` (made from the voice track).
- `assets/kit.js` has the shared helpers (cues, camera, marker fills, draw-ons, pops).

### Rebuilding the audio

```bash
python tools/voice.py          # Kokoro TTS per line (am_michael, 0.92x) -> assets/voice/*.mp3, timing, lip-sync
python tools/music.py          # loops and ducks the MusicGen clips -> assets/music/bed.mp3
node tools/build.mjs           # rewrite index.html with the new timing
```

`voice.py` needs `pip install kokoro-onnx soundfile numpy` and the Kokoro model files that
`npx hyperframes tts` downloads to `~/.cache/hyperframes/tts/`. `music.py` needs numpy and ffmpeg.
To re-voice the film with a different voice, change `voice`/`speed` in `script/script.json` and run
all three commands; the animation follows the new timing.
